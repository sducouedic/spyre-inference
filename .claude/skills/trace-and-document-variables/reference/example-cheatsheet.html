Scenario 3 — pure decode, 5 sequences bucketed to 8

bucketed decode dispatch SPYRE_BUCKETED_DECODE=1 · num_seqs=5 ≥ _MIN_SEQS_BUCKET(4) · max_query_len=1 · no sliding window
